# BlessCloud temple assets

Public static runtime resources for the three BlessCloud temple scenes. No user data, credentials or server configuration is included.

Characters use the user-provided textured male/female models, reduced to 60,000 triangles each, with the existing procedural action rig. Profile gender 1 selects male; gender 2, unset or undisclosed selects female.

The web entry remains on the application server. Runtime scripts and multipart model resources may load through jsDelivr, with an identical server mirror and SHA-384 integrity checks. Pin consumers to an immutable Git commit.
